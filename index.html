5 步驟完整解析
1

安裝 Git 與設定全域身分 前置準備

Git 是本地的版本控制核心，GitHub 則是雲端代碼儲存庫。

A. 下載與安裝 Git
  • 前往 git-scm.com 下載 Windows 安裝檔，安裝步驟維持預設直按 Next 即可。
  • 安裝完成後打開終端機輸入 git --version 檢驗。
B. 配置全域使用者身分 
git config --global user.name "你的名字"
git config --global user.email "你的GitHub信箱@example.com"
2

專案架構、Dockerfile 與必要檔案 雲端規則

Render 需要依據目錄檔案決定如何安裝依賴（Build Command）以及如何常駐啟動（Start Command）。

專案根目錄必備結構與 Dockerfile 設定
Python 專案要求
3

GitHub 開新專案與本地推送 (Git Push) 代碼上傳

在 GitHub 點選「New repository」建立空白儲存庫，並執行標準推送指令。 

# 1. 進入專案目錄並初始化 Git
git init

# 2. 將所有檔案加入暫存區
git add .

# 3. 提交版本記錄
git commit -m "feat: initial commit for deployment"

# 4. 指定主分支名稱為 main
git branch -M main

# 5. 關聯到你在 GitHub 建立的倉庫 (例如 Albertyoung22/githuv_render_op)
git remote add origin https://github.com/你的帳號/你的專案.git

# 6. 推送至 GitHub (密碼請輸入 GitHub Token)
git push -u origin main
4

註冊 Render 並授權連結 GitHub 倉庫 雲端連接

前往 render.com 點選「Sign in with GitHub」，直接授權存取剛剛建立的倉庫。

① 免密碼一鍵登入

點擊 "Sign in with GitHub"，免手動輸入帳號密碼，自動連動。

② 儲存庫權限授權

可選擇「All repositories」或指定特定的公開/私有倉庫給予 Render 存取。

③ 準備建立服務

進入 Dashboard 點選「New +」選擇 Web Service 或 Static Site。

5

參數配置、通訊埠 (PORT) 綁定與完成發布 關鍵細節

若為 Web Service，請注意伺服器必須監聽 0.0.0.0 與環境變數 $PORT。
